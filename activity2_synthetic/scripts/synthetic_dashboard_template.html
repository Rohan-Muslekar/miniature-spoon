How the merge works

Both tables are mapped to a shared schema — source, id, title, year, genre, runtime, rating, votes — then stacked. Synthetic-only fields (country, budget_million, revenue_million, content_rating) stay empty for real rows. The full merged file is saved as combined_movies.csv.

Why flag the source

Mixing invented rows into real data without a marker is how synthetic data silently contaminates an analysis. The source column keeps them separable so every later step can include, exclude, or compare them on purpose.
